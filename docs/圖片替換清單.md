# 圖片替換清單

本站目前使用的圖片，全部截取自樓宇滲漏水聯合處理中心《處理樓宇滲漏常識》（2023 年 09 月）。
為降低版權風險，建議把當中的**實拍相片**換成自行拍攝的照片。本清單列出每張相片的用途、出現位置與拍攝建議。

**替換方法：** 用同一個檔名覆蓋 `assets/img/` 內的檔案即可，網頁毋須改動。
（如檔名不同，需同時修改 `content/` 內的片段與 `assets/js/data.js`。）

### 拍攝共通建議

- **解像度**：長邊不少於 1200px 拍攝，再按上表縮至建議尺寸（可用 `tools/` 內的方式或任何看圖軟件）。
- **檔案大小**：JPEG 品質 80、單張控制在 150KB 以內，網頁載入才夠快。
- **私隱**：不要拍到門牌、單位號碼、車牌、可辨識的人臉；如無法避免請先打格。
- **取得同意**：拍攝他人單位或大廈公共部分，先徵得業主／管理公司同意。
- **保留原檔**：原檔另存一份，日後如需不同尺寸可重新輸出。

## C. 完成替換後

1. 更新 `source.html`（即 `content/source.html`）的「圖片出處」一節，改為說明哪些是自攝、哪些仍引用刊物。
2. 執行 `python3 tools/build_pages.py` 重新產生頁面。
3. 提交並推送，GitHub Actions 會自動重新部署。
