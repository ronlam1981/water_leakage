### 待補的品牌資產

手冊第 27 頁列為「下一階段必補資產」，本站受此限制：

- **橫式三語標誌的向量版** —— 現用 640 × 218 px 點陣檔（由客戶提供的原圖裁切、
  縮放，並把 JPEG 壓縮在白底留下的雜訊還原為純白），顯示尺寸 320 px 即 2 倍解像度，
  已合乎手冊「橫式三語 ≥ 320 px 數碼」。取得 SVG／AI 主檔後可再替換
  `assets/img/uvision-logo-h.*`，以支援更大尺寸與印刷。
- **頁首標誌** —— 橫式標誌比例約 3:1，放入 62 px 高的頁首時寬度需縮至約 120 px，
  三語副行會看不清；按手冊「小尺寸先簡化」原則，頁首改用符號標誌。
- **反白向量版** —— 手冊明言不可把現有點陣圖直接反相或去底，因此深藍色頁尾未放標誌。
- 取得正式向量主檔後，頁首與頁尾可即時換上。

## 搜尋引擎

兩頁都可被收錄，**沒有使用 `noindex`**：兩頁針對不同搜尋意圖——
公益版是資訊型（「滲漏水點自己查」），落地頁是求助型（「樓上唔認點算」），
內容重疊低，且落地頁是官網連入的目標，封鎖它等於浪費那些連結。

- 兩頁各有自我指向的 `<link rel="canonical">` 與 `og:url`，
  令 `?v=2` 之類的快取參數網址不會分散排名訊號。
- `sitemap.xml` 列出兩條網址，需在 Google Search Console 手動提交
  （`robots.txt` 只在網域根目錄生效，專案倉庫放不了，
  而預設無 `robots.txt` 即全站可爬，正是本站想要的結果）。
- 日後若判斷兩頁互搶排名，應先看 Search Console 數據再調整標題與內部連結，
  而不是加上不可逆的 `noindex`。

## 技術

純靜態 HTML + CSS，**沒有框架、沒有追蹤程式、不收集任何資料**。

按「複製號碼」時把微信號碼寫入剪貼簿，
不載入任何外部程式庫、不發送任何請求。
