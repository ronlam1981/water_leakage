# 澳門樓宇滲漏水自查互動指南

一個單頁、純靜態、可離線使用的互動網頁工具，幫助澳門居民在遇到樓宇滲漏水或塞渠問題時，
按官方認可的方法**逐步自我檢測**，盡量找出可能的滲漏源頭；若仍未能確定，亦清楚指引下一步的求助途徑。

🔗 **網站：** https://ronlam1981.github.io/water_leakage/

## 互動自檢的判斷邏輯

自檢決策樹定義在 [`assets/js/data.js`](assets/js/data.js)，共 20 個節點，分成三類：

- **`question`** — 觀察題（滲漏形態、滲漏位置）
- **`test`** — 動手測試（24 小時觀察記錄法、總水掣＋水錶測試、放水測試）
- **`result`** — 結論（供水管／排污渠／垂直立渠／單位內淤塞／公共渠／街道渠網／共同部分／協商受阻／未能確定／外牆／凝結水／冷氣機滴水）

主要分流依據刊物「測試錦囊」的原文：

- 24 小時不停滲出、沒有污漬或臭味 → **通常都是供水管滲漏**
- 某些時段滲漏特別嚴重，且有污漬或異味 → **通常都與排污渠有關**
- 天花或牆身頂部 → **通常與上層單位有關**；地板或牆腳 → **可能與相鄰單位有關，但亦可能是自己單位**
- 牆身滲漏 → **有可能是樓宇的垂直排污渠問題，屬整體業主的責任**
- 排污口去水不暢順或反湧 → **通常都是渠道或沙井淤塞引起，疏通是最快捷見效的**

## 技術

- 純靜態：HTML + CSS + 原生 JavaScript，**沒有任何建置步驟、沒有框架、沒有追蹤程式**
- 自檢過程只在瀏覽器記憶體中運行，**不會上載或儲存任何個人資料**
- 響應式設計，手機（≥ 320px）至桌面均可使用；支援列印／存成 PDF
- QR Code 為預先產生的 SVG（`assets/qr/`），不依賴任何第三方服務

```
*.html                根目錄的 11 個頁面（由 tools/build_pages.py 產生，請勿直接改）
content/*.html        每一頁的內容片段 ← 要改內容就改這裡
tools/build_pages.py  套上共用頁首／頁尾，輸出根目錄的各頁面
assets/
  css/style.css       版面與配色
  js/data.js          自檢決策樹、求助途徑、反映資料清單
  js/app.js           互動引擎（渲染、進度、上一步、重新開始、產生記錄）
  img/                自刊物截取的圖片
  qr/                 vCard / WhatsApp / 電話 / 電郵 / 微信 / IG / Threads / FB / 地圖 / 本站
.github/workflows/pages.yml   推送即自動部署到 GitHub Pages
```

> 根目錄的 `.html` 是**產生出來的檔案**。修改內容請改 `content/` 內的片段（或 `tools/build_pages.py` 的頁首頁尾），
> 然後執行 `python3 tools/build_pages.py` 重新產生，再一併提交。

git add -A && git commit -m "更新內容" && git push
